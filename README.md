# Аԥсуа шрифтқәа — каталог абхазских шрифтов

**Сайт:** https://djonua.github.io/abkhaz-fonts/

Автор — Джонуа Дамей.

В публичном репозитории — только страница каталога и CSV-таблицы. Рабочие данные сканирования (`data/`, `scripts/`) хранятся локально.

Проект по инвентаризации шрифтов с поддержкой абхазского алфавита. Источники: Google Fonts, MyFonts, магазин Type Department, ParaType, type.today, Contrast Foundry, Schrift Foundry и Шрифтовик. Также проверены сайты TypeType (подходящие шрифты уже есть в каталоге через MyFonts), Brownfox, Letterhead, Russian Fonts, fa-fa-fa.xyz и nicetype.ru (новых абхазских шрифтов нет).

## Итоговые файлы

- **`abkhaz-fonts.html`** — интерактивная страница каталога, 436 шрифтов (94 Google Fonts + 323 MyFonts + 1 Type Department + 13 ParaType + 1 type.today + 2 Contrast Foundry + 1 Schrift Foundry + 1 Шрифтовик). В шапке — сводка: общее число, полоса «Поддержка алфавита» и полоса «Источники»; список источников строится из `SRC` по убыванию числа шрифтов и сворачивается до семи, если источников больше восьми. Вторая фраза описания в шапке — список проверенных сайтов — собирается скриптом из массива `CHECKED` (название и число шрифтов на сайте); первая фраза про MyFonts и Google Fonts и последняя («Отобраны все шрифты, в которых есть абхазские буквы») статичные. Число шрифтов по источникам — в сводке под описанием. Открывать двойным кликом по **`Открыть каталог.command`** — он поднимает локальный сервер и открывает страницу на `http://localhost:8765`. При открытии файла напрямую (`file://`) MyFonts не рендерятся: компоненту Monotype нужен `crypto.subtle`, который есть только на https/localhost (страница покажет предупреждение). Есть мобильная версия (до 720px): сверху липкая строка «поиск + Фильтры», все фильтры и настройки образца — в шторке снизу, кнопка «наверх». У шрифтов Google Fonts есть кнопка «Скачать»: браузер тянет все начертания и лицензию из репозитория google/fonts на GitHub и отдаёт одним ZIP (нужен интернет). Целиком бесплатных шрифтов на MyFonts в каталоге нет: у 10 семейств бесплатны только отдельные начертания (список — `FREE_STYLES` в HTML), у них ссылка «Бесплатные начертания» и отдельный пункт в фильтре «Стоимость». Шрифты Type Department, Contrast Foundry и Шрифтовика набирают образец файлом с сайта издательства — тем же, что грузит тестер на странице шрифта (поле `file` в `FONTS`); файл загружается, когда карточка появляется на экране. У шрифтов ParaType образец — картинка с их рендерера (поле `rid` — номер начертания), разрезанная на строки по пробелам. Если абхазские буквы есть не во всех начертаниях, это написано в карточке (поле `note`). У бесплатных шрифтов ParaType ссылка «Бесплатно на ParaType». У Agse (type.today) и Struve (Schrift Foundry) живого образца нет (поле `nosample` — пояснение вместо набора): type.today отдаёт только урезанные файлы без абхазских букв, а файлы Schrift Foundry открыты только их собственному сайту. Если шрифт продаётся на нескольких сайтах, карточка одна, остальные сайты — дополнительными ссылками (поле `more`).
- **`abkhaz_fonts_google_pilot.csv`** — CSV-каталог Google Fonts, UTF-8 с BOM, разделитель `;`. Колонки: Шрифт, Поддержка абхазского, Категория, Автор, Лицензия, Цена, Файлов, Ссылка.
- **`abkhaz_fonts_myfonts.csv`** — CSV-каталог MyFonts, UTF-8 с BOM, разделитель `;`. Колонки: Шрифт, Издательство, Цена (USD), Бесплатный, Начертаний, Поддержка абхазского, Недостающие символы, Кол-во недостающих, Ссылка.
- **`abkhaz_fonts_type_department.csv`** — CSV-каталог Type Department в том же формате, что и MyFonts; цена — в фунтах за одно начертание (лицензия для компьютера).
- **`abkhaz_fonts_paratype.csv`** — CSV-каталог ParaType в том же формате; цена — «от» в рублях, как в каталоге paratype.ru.
- **`abkhaz_fonts_type_today.csv`** — CSV-каталог type.today в том же формате; поддержка — по данным сайта.
- **`abkhaz_fonts_contrast_foundry.csv`** — CSV-каталог Contrast Foundry в том же формате; цена — минимальная, в долларах.
- **`abkhaz_fonts_schrift_foundry.csv`** — CSV-каталог Schrift Foundry в том же формате; цена — «от» в рублях с type.today (на сайте студии цен нет).
- **`abkhaz_fonts_shriftovik.csv`** — CSV-каталог Шрифтовика в том же формате; цена — самая дешёвая лицензия (XS) в рублях.

## Абхазские символы (28 знаков — 14 пар)

Ӷӷ Ӡӡ Ққ Ҟҟ Ԥԥ Ҭҭ Ҳҳ Ҵҵ Ҷҷ Ҽҽ Ҿҿ Ҩҩ Џџ Әә

Также проверялось наличие устаревшей формы Ҧ (U+04A6/04A7).

## Что где

### `/scripts/`
- **`scan.py`** — питон-скрипт сканирования Google Fonts через fontTools: обходит клон репозитория `google/fonts`, читает cmap каждого файла и ищет 28 абхазских знаков.
- **`tpl.html`** — HTML-шаблон страницы (до наполнения данными).
- **`cmap_check.js`** — проверка абхазских знаков в веб-шрифтах прямо в браузере, без скачивания файлов: читает cmap у OTF/TTF/WOFF, у WOFF2 сравнивает ширину знаков с эталонами PT Sans и PT Mono. Вставляется в консоль на странице магазина.
- **`paratype_scan.py`** — проверка шрифтов ParaType через API таблицы глифов сайта (блоки Cyrillic и Cyrillic Supplement, только глифы с контуром). Запросы идут через curl: сервер `renderer2.paratype.ru` не отдаёт промежуточный сертификат.

### `/data/`
- **`gf_scan.json`** — сырой результат сканирования Google Fonts (все 2 030 семейств).
- **`combined_fonts.json`** — первый объединённый список (без md5).
- **`combined_v2.json`** — 449 шрифтов с md5-хэшами для MyFonts.
- **`combined_filtered.json`** — 432 шрифта после ручной чистки ложноположительных.
- **`style_check.json`** — результаты автоматической проверки стиля (шрифты, не прошедшие её): оценки «латиница/кириллица» и «основа/абхазская буква».
- **`removed_style.json`** — шрифты, убранные из каталога после проверки стиля.
- **`handles.json`** — handles (URL-slugs) 355 MyFonts шрифтов.
- **`md5_map.json`** — таблица handle → md5 для запросов к Monotype API + флаг Ҧ.
- **`fonts_embed.json`** — Google Fonts с base64-встроенными WOFF (5 МБ).
- **`type_department.json`** — результат проверки всех 175 шрифтов Type Department: статус каждого товара и найденный шрифт.
- **`typetype.json`** — результат проверки всех 77 семейств TypeType: какие абхазские знаки есть в каждом.
- **`paratype.json`** — результат проверки 1 390 шрифтов ParaType: статус каждого, какие добавлены, какие уже были в каталоге и какие пропущены как дубли; начертания добавленных.
- **`type_today.json`** — все 316 гарнитур type.today с пометкой, указан ли абхазский, и заметки по двум найденным.
- **`brownfox.json`** — все 22 семейства Brownfox: какие абхазские знаки есть в каждом.
- **`contrast_foundry.json`** — 26 гарнитур Contrast Foundry: сколько абхазских знаков в главном начертании, какие добавлены и какие пропущены как дубли.
- **`letterhead.json`** — 167 шрифтов Letterhead: набор знаков по описанию или по картинке набора.
- **`russian_fonts.json`** — 14 гарнитур Russian Fonts: полный или урезанный файл тестера, заявленные языки, вывод.
- **`shriftovik.json`** — 30 шрифтов Шрифтовика: списки языков с сайта, у восьми — проверка файла тестера и пробной версии.
- **`fa_fa_fa.json`** — три шрифта Фёдора Аброськина (fa-fa-fa.xyz): набор знаков по описанию или картинке.
- **`nicetype.json`** — шрифты Александры Корольковой по ссылкам с nicetype.ru, сверенные с проверкой ParaType.
- **`schrift_foundry.json`** — 6 семейств Schrift Foundry: абхазские знаки в каждом из 23 начертаний по файлам тестера.

## Методология

### Google Fonts
Проверены все 2 030 семейств из репозитория google/fonts. Каждый файл-начертание открыт через `fontTools`, из `cmap` извлечён набор поддерживаемых code points, сверен со списком абхазских знаков + базовая кириллица А–я. Семейство считается «полным», если все его начертания содержат все знаки. Также отдельно проверялось наличие Ҧ (U+04A6). Все GF — лицензия SIL Open Font License.

### MyFonts
Через Algolia API (`search-myfonts-api.monotype.com`, index `universal_search_data`) выбраны все семейства с поддержкой русского языка (~5 000 шрифтов). Для каждого через Monotype `render-string` API проверено наличие каждого из 28 абхазских знаков. Отфильтрованы шрифты с полной или частичной поддержкой (не хватает до 4 символов). Затем вручную удалены 17 CJK/скриптовых шрифтов, где API давал ложноположительный результат — глифов в реальном WOFF-сабсете нет. Позже убраны два дубля: MS-Mincho (тот же файл, что MS Mincho, — одинаковый md5) и Atwic Pro (тот же рисунок, что Atwic Cyrillic).

### Type Department
Список всех 175 товаров взят из `/products.json` (магазин на Shopify). Со страницы каждого шрифта взяты веб-шрифты тестера (`initialFontData`, лежат в Firebase Storage) и в браузере прочитана таблица символов (`scripts/cmap_check.js`). Сначала проверялось одно начертание семейства, у найденных — все. Полная поддержка — только у Non Ophelie (Non Foundry), все 12 начертаний; рисунок абхазских букв просмотрен вручную. Кириллица без абхазских букв — у 16 семейств. Не проверено 12: у 11 нет тестера (Bunkel и 10 бесплатных шрифтов, их выдают после подписки), у Cross Black сайт отдаёт пустой файл.

### TypeType
Список всех 77 семейств взят из `sitemap-posts-product-1.xml`. На странице шрифта все начертания подключены через `@font-face` (`/wp-content/uploads/*.woff`), в браузере прочитан cmap обычного начертания каждого семейства. Кириллица есть у всех. Подходят четыре: TT Norms Pro и TT Commons Pro (полная поддержка), TT Hoves Pro и TT Commons Classic (нет Ԥ ԥ) — все уже есть в каталоге через MyFonts, результаты совпали. Подборки сайта «Абхазский» и «Абхазский+» показывают те же TT Norms Pro и TT Commons Pro. Ближе остальных TT Trailers — 18 знаков из 28.

### ParaType
Список шрифтов взят из API каталога (`api.paratype.ru/api/catalog`, по 100 за запрос): 1 381 в общей выдаче и ещё 9 только в русской (заголовок `Accept-language: ru`), всего 1 390. У главного начертания каждого шрифта через API таблицы глифов (`renderer2.paratype.ru:8443/api/glyphs/databysize`, блоки 8 и 9) получены коды знаков; пустые глифы без контура не засчитывались. Подходят 33 семейства: 16 уже были в каталоге через MyFonts и Google Fonts; PT Sans Expert, PT Serif Expert и их версии Com — тот же рисунок, что PT Sans и PT Serif, с расширенным набором знаков, их не добавляли, чтобы не дублировать; 13 добавлены. Перед добавлением названия сверены со всеми списками проекта (каталог, полный скан Google Fonts, 449 шрифтов MyFonts до чистки, убранные по стилю). У добавленных проверены все начертания: у Courier PT абхазские буквы есть только в Bold, у DeepFont — в 13 начертаниях из 15 (и без Ԥ ԥ). Рисунок букв просмотрен по картинкам рендерера. Фильтр сайта «Абхазский» даёт 35 шрифтов, но у Futura и Postulat абхазских букв нет ни в одном начертании.

### type.today
Данные всех 316 гарнитур (из них 46 в архиве) взяты из `__NEXT_DATA__` одной страницы сайта (`props.initialState.fonts`); раздел `/api/` закрыт в `robots.txt`, его не использовали. Публичные файлы тестера (`public_file` — WOFF в data-URI, `public_file_without_encoding`) — урезанные наборы: латиница и русская кириллица, около 230 знаков, абхазских букв в них нет даже там, где абхазский заявлен. Полных файлов сайт не отдаёт, поэтому проверка по cmap невозможна. Абхазский указан в `language_titles` у двух гарнитур — Struve (Schrift Foundry) и Agse (Елена Новосёлова); их таблицы глифов на страницах (`charMap` — контуры без кодов символов) просмотрены вручную, абхазские буквы есть, Ԥ на глаз не опознана. Обе добавлены по данным сайта, без живого образца. Struve потом проверен по файлам Schrift Foundry (см. ниже): Ԥ ԥ в нём нет, вместо неё старая Ҧ; его карточка перенесена на Schrift Foundry.

### Brownfox
brownfox-type.ru не отвечает (порты 80 и 443 закрыты), проверен сайт студии brownfox.org. Список шрифтов и файлы тестера (WOFF2 в `cdn.sanity.io`, поле `weights[].files.display`) взяты из RSC-данных страницы; файлы не урезаны — казахская, украинская и сербская кириллица в них есть. WOFF2 проверены в браузере сравнением ширин знаков с эталонами PT Sans и PT Mono. Все 152 начертания 22 семейств: абхазских букв нет, максимум 6 знаков из 28 (Қ қ, Ә ә, Џ џ).

### Contrast Foundry
Список гарнитур — из `__NEXT_DATA__` главной и `/sans-global` (26 гарнитур). Файлы начертаний лежат на S3 (`cofo-uploads-prod`, CORS `*`) и перечислены в `fontData.font_styles[].licenses[].files` на странице гарнитуры; эти же файлы грузит тестер сайта. Поле `chars` — только превью, не полный набор знаков. Прочитан cmap одного начертания каждой гарнитуры, у подходящих — всех. CoFo Sans Pro — полная поддержка во всех 16 начертаниях и в вариативном шрифте; CoFo Glassier — нет Ҩ ҩ. Версии CoFo Sans Pro с арабской, армянской, еврейской и деванагари письменностями — тот же рисунок латиницы и кириллицы, пропущены как дубли.

### Letterhead
Сайт на Tilda: тестера и файлов шрифтов нет, шрифты показаны картинками, проверка по cmap невозможна. На всех 167 страницах прочитано описание набора знаков: у 153 — «алфавит русского языка». Для остальных просмотрены картинки с полным набором знаков (`*_glyphs.png`): русская или славянская кириллица, абхазских букв нет. У четырёх страниц (Modulario, Aeronautic, All Caps, Attic) нет ни описания, ни картинки набора.

### Russian Fonts
Список — `wp-sitemap-posts-product-1.xml` (14 гарнитур). Файлы тестера (`/wp-content/uploads/…`, CORS для чужих сайтов закрыт) прочитаны в браузере на russianfonts.ru. У пяти гарнитур файлы полные (Barbariska, Boris, Gora, Krabuler, Dobrozrachniy): абхазских букв не больше 10 из 28. У девяти (четыре Dewi, Rostin, Rufo, Takt, Tone, Boris Serif) файлы тестера урезаны до русского алфавита, поэтому учтена заявленная языковая поддержка — языков с абхазскими буквами в ней нет.

### Шрифтовик
Сайт на Tilda; список товаров — из API магазина Tilda (`store.tildaapi.com/api/getproductslist`, 30 шрифтов). Тестера и веб-шрифтов нет. У 22 шрифтов на странице есть автоматический список поддерживаемых языков — абхазского нет ни в одном (из кириллических: русский, белорусский, болгарский, македонский, сербский, осетинский, чеченский). У восьми списка нет (Blocktura, Concretica, Femme Fatale, Luns Muns, Nowatorus, Primo, Pupok, Saturnika), зато есть тестер: полный TTF на Dropbox (`window.fontConfig.fontUrl` на странице, CORS `*`). Его cmap прочитан в браузере, пустые глифы не засчитывались. SK Blocktura (Тихон Резцов, одно начертание Extra Black) — полная поддержка и Ҧ, рисунок абхазских букв просмотрен вручную, добавлен. У шести других из абхазских букв есть только Џ џ, у SK Primo — ни одной. Пробные версии тоже проверены: они урезаны до латиницы или до русского алфавита без Й и Ё, по ним поддержку не определить.

### fa-fa-fa.xyz
Сайт Фёдора Аброськина на Tilda: три шрифта (Nada, René, Resin), тестера и файлов нет. По описаниям и картинке набора знаков — базовая кириллица (у Nada ещё белорусская и украинская, у Resin — сербская и македонская), абхазских букв нет. Страница Stencils — физические трафареты.

### nicetype.ru
Личный сайт Александры Корольковой: шрифты не продаются, 28 ссылок ведут на paratype.ru и одна на MyFonts. Шрифты ParaType сверены с результатами проверки ParaType: полный абхазский алфавит у PT Sans, PT Serif, PT Mono, PT Sans Pro и PT Serif Pro — все уже в каталоге; у остальных (Circe, Fact, Golos, Hint и др.) не больше 12 знаков из 28. FF Carina и Cless по ссылкам больше не продаются.

### Schrift Foundry
Список — страница `/collection/retail-fonts`: в продаже 6 семейств (Struve, Bering Stencil в трёх ширинах, Retros и нотный Rufus), остальные шрифты студии ещё не вышли или выдаются по запросу. Сайт на Fontdue: все начертания перечислены в CSS `fonts.fontdue.com/schrift-foundry/css/…`, файлы WOFF2 не урезаны (контрольный набор расширенной кириллицы — 32 из 32). Файлы загружены в браузере на schriftfoundry.com — другим сайтам Fontdue вместо файла отдаёт переадресацию — и проверены сравнением ширин знаков с эталонами PT Sans и PT Mono. Struve — во всех 10 начертаниях нет только Ԥ ԥ, есть Ҧ; то же видно в таблице глифов на странице. Он же продаётся на type.today, поэтому одна карточка со ссылками на оба сайта. Bering Stencil (12 начертаний) и Retros — 10 знаков из 28; у Rufus (нотный шрифт) букв и тестера нет. Список поддерживаемых языков одинаковый на страницах всех коллекций (абхазский в нём указан), поэтому не использовался. Цены на сайте студии нет, в карточке — цена type.today.

### Живой рендер
- **Google Fonts**: WOFF-файлы встроены в HTML как base64 data-URI (~5 МБ).
- **MyFonts**: официальный компонент Monotype `<font-preview>` (`web-font-preview-service` 2.0.3). Для каждого шрифта грузится сабсет WOFF2 только с глифами показываемого текста. Требует интернет.
- **Type Department**: шрифт грузится через `FontFace` с сервера магазина — тот же файл, что использует тестер на странице шрифта (Firebase Storage отдаёт его любому сайту, CORS `*`). Загрузка — когда карточка появляется на экране, как у MyFonts. Образец и строка алфавита набираются этим шрифтом. Требует интернет.
- **Contrast Foundry**: так же, как Type Department, — `FontFace` с файлом тестера (S3, CORS `*`).
- **Шрифтовик**: так же — `FontFace` с файлом тестера (TTF на Dropbox, CORS `*`, около 500 КБ).
- **type.today и Schrift Foundry**: живого образца нет, вместо него пояснение в карточке.
- **ParaType**: веб-шрифты ParaType (`files.paratype.ru/webfonts/…`) отдаются только сайту paratype.ru, поэтому образец — картинка их рендерера `files.paratype.ru/renderer/{id}/pangram.png` (CORS `*`). Рендерер рисует текст одной строкой, обрезанной по краям букв; страница находит в картинке промежутки между словами и режет её на строки по ширине карточки, так что базовая линия у всех строк общая. Перерисовка — при смене текста, кегля или ширины, с задержкой 250 мс. Строка алфавита — системным шрифтом, как у MyFonts. Требует интернет.

## Известные ограничения

1. Артефакт claude.ai блокирует внешние скрипты — MyFonts не рендерятся. Открывать HTML напрямую в браузере.
2. API Monotype может давать ложноположительные результаты для CJK-шрифтов, где символы «есть» в декларации, но глифов в реальном сабсете нет. Такие шрифты удалялись вручную.
3. Наличие символа не гарантирует, что он нарисован в стиле шрифта. Автоматическая проверка сравнивает пары букв (A/А, o/о… и К/Қ, Т/Ҭ…); подозрительные шрифты просматриваются вручную на странице **`review.html`** (открывать через **`Открыть проверку шрифтов.command`**).
4. Образцы Type Department, Contrast Foundry и Шрифтовика зависят от ссылок на файлы тестера на их сайтах (у Шрифтовика это ссылки Dropbox). Если сайт их сменит, вместо образца карточка покажет сообщение со ссылкой на страницу шрифта.
5. Рендерер ParaType молча выбрасывает знаки, которых нет в шрифте (например, Ҕ и Ҧ в образце «Алфавит»). Какие буквы отсутствуют, видно по строке алфавита в карточке.
6. Agse (type.today) добавлен по данным сайта: файл проверить нельзя, живого образца нет. У Struve (Schrift Foundry) файлы проверены, но живого образца тоже нет.
